- [SECURITY_AUDIT.md](../../SECURITY_AUDIT.md) — active security findings
- [DAPPS_ALIGNMENT_REVIEW.md](../../DAPPS_ALIGNMENT_REVIEW.md) — code-vs-documentation audit
- [MASTER_REFACTOR_PLAN.md](../../MASTER_REFACTOR_PLAN.md) — forward-looking operating model
- [CLAUDE.md](../../CLAUDE.md) — project conventions

| Directory | Contents |

| `misc/` | `plan.md` (UI update plan), `ARC_SDK_INTEGRATION.md` (documents the deleted `arc-client.ts`), `BASELINE_ALIGNMENT.md`, `UX_AUDIT_SHELL_AND_HOMEPAGE.md` |
