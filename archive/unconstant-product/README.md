# Archived: unconstant product (OpenSea mall + shell)

This folder is the **old product identity**. It is not a roadmap.

## What “unconstant” was

ARC tried to be several products at once:

- An OpenSea clone (listings, auctions, studio, 97% feature-parity docs)
- A “Phase 1 platform unification / connected shell” (stats, rewards, route continuity banners)
- A token launcher tab on the side

The UI explained the protocol and the shell. Creators were paid only at graduation. Home dressed NFT listings up as token launches. That track is mothballed.

## What won

See [`PRODUCT.md`](../../PRODUCT.md) at the repo root.

**ARC is a USDC-native token launcher.** Creators earn on every trade. Traders buy a live curve. Unsold supply cannot be yanked.

NFT studio, listings, auctions, XP, and rewards remain in the codebase as a library. They are not the product and these files must not be used to justify building them.
